首次连接 / 排查

手机和 Orin 在同一 Wi-Fi。安卓 Chrome 使用终端打印的 HTTPS 地址，首次连接请从下方下载本程序生成的 CA 证书。

下载本机 CA 证书

安卓设置 → 安全 → 安装证书 → CA 证书，装好后重新打开页面并允许麦克风。保持页面在前台，不要锁屏。结束收音、网络断开或摄像头中断时取消尚未确认的操作。
