## 2026-11-04｜两个工作页，共用摄像头和模型

### 方案与理由

用户同意把日常识别与现场学习分为两个页面。识别页保留左边问答、右边实时画面；学习页左边采集，右边管理图片和视频。顶部集中放模型选择、验证、启用、删除和打开素材目录。

### 遇到的困难

原实验的学习入口不能直接作为新项目依赖。切页还会遇到迟到的语音理解结果、尚未结束的手势确认以及正在发送的回调，单纯隐藏按钮无法保证不再发命令。当前工具环境也不能连接 DISPLAY=:1，不能把回调模拟测试当成真实窗口验收。

### 怎么解决的

把旧版按方向、尺度、手形覆盖选样的数值算法迁入独立的 learning 模块；采集时同步保存关键点，学习时不重读录像。先覆盖错例和不同姿态，再回放本批关键点，补充仍识别错误的真实参考。当前基础模型的参考库保留，新模型另存并记录父模型路径和摘要。

S 保存图片，V 录参考视频，T 录独立验证视频。图片和视频有分栏及删除操作，删除只排除学习条目并保留文件。保存成功把本批目录归档为用户填写的模型名，创建新批次并清空列表和预览；没有图片也可以只用视频学习。新模型不会因保存而自动启用，先选中验证，再明确启用。

学习模式在控制器的最终发送层阻断指令，并使旧语音令牌失效。切页会取消未确认请求和旧的语音回答；已开始的发送先结束，切换完成后不再发送新命令。返回识别页生成新的接收令牌并重新要求 OK 准备。机械臂已经收到的动作不因切页撤回。

### 结果与证据

原来的 102 项自动测试继续通过。新增数值学习、素材恢复、验证集隔离、原始帧未被绘制污染、基础模型溯源、重复名称保护、模式切换竞争、共享摄像头和输入框快捷键等测试，合计 118 项通过。测试使用合成关键点、生成的空白数组和模拟设备，没有读取用户保存的图片或视频。

`python run.py --check` 通过，Python 语法和 Git 空白检查通过。没有增加 requirements 依赖，也没有修改原实验目录及其模型。

### 未决问题与下一步

实际拍照、MP4 编码、图片预览、桌面布局及手机与相机联动还需用户实机确认。独立验证报告会分别显示有效手部帧准确率及未检测到关键点的帧数；训练素材回放成绩只说明本批拟合，旧模型回退检查也只覆盖已有数值参考，不能代替其他场景验证。
