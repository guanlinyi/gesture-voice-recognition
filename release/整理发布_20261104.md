## 2026-11-04｜保留已经验证的行为，整理代码和部署方法

### 方案与理由

原来的手势＋语音控制已经由用户实机测试通过。这里保留确认、取消、超时、持续收音、聊天、指令输出和机械臂方向互斥的逻辑，按手势、转写、合成、聊天、手机接口等职责整理，入口只负责组装。

### 遇到的困难

原入口引用了多个实验目录，直接复制无法独立运行。模型较大，运行时还会产生证书和日志，也不适合一起上传。精简学习模型的原 JSON 还包含采集来源路径。

### 怎么解决的

运行代码全部放进 `steering_control/`，移除了对原项目 Python 模块的导入，去掉了本实验不需要的学习、采集和模型管理界面。导出 73 个参考样本时只保留标签和数值特征，没有读取图片或视频。

本机通过被忽略的 `config.local.json` 复用已有权重和引擎；已有 sherpa-onnx 包复制到被忽略的 `data/python/`，没有改动 Python 环境。新机器使用 `requirements.txt` 和 `prepare.py` 准备依赖及模型。下载保留续传机制，模型使用固定摘要校验；相机初始化脚本由配置指定，不带密码。

### 结果与证据

- 原实验整体验证：用户明确反馈已经实机测试通过，这是整理前的结果。

- 数值一致性：对 73 个原始数值特征分别加上 5 档扰动，共 365 例，原库与导出库的预测结果完全一致。只读取数值 JSON，没有读取原视频或图片。
